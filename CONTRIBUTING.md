# Contributing to React-Awesome

Thanks for contributing! This is a curated list — quality over quantity.

## How to add a library / tool

1. Fork + create a branch.
2. Add entry in the correct section of `README.md`, alphabetically where possible.
3. Format:
   ```md
   - [Name](https://github.com/org/repo) — One-line factual description. What it does + who it's for.
   ```
4. Commit + open a PR with a short reason why it belongs here.

## Acceptance criteria

- [ ] Directly useful for **React (web)** or **React Native** developers (libs, UI kits, tools, frameworks).
- [ ] No courses, tutorials, templates, or personal dotfiles.
- [ ] Maintained: commit in last 12 months OR >1k stars + stable / widely adopted (e.g. Formik, Recoil).
- [ ] Link goes to official repo or official docs, not a blogmirror.
- [ ] No duplicates — check existing sections first.
- [ ] React Native-only goes under RN; universal (Web + Native) goes under Cross-Platform.

## PR checklist

- One-line description, no marketing fluff.
- Correct section + working link.
- Keep the diff minimal (don't reformat the whole file).

Small PRs (1–3 entries) get reviewed fastest.
